# Прогресс обучения

Это один и тот же проект — «Программа обработки садоводческих участков» — который
развивался в течение года вместе с изучаемыми темами C++. Ниже показано, какой этап
какую тему закрепляет.

**Финальная версия (наследование) лежит в `src/`**, ранние снапшоты — в `archive/`.

| Этап | Папка | Тема |
|:----:|-------|------|
| 01 | [`archive/01-arrays`](../archive/01-arrays) | Массивы, структуры, функции |
| 02 | [`archive/02-dynamic-arrays`](../archive/02-dynamic-arrays) | Динамическая память |
| 03 | [`archive/03-classes`](../archive/03-classes) | Классы и инкапсуляция |
| 04 | [`archive/04-classes-dynamic`](../archive/04-classes-dynamic) | Класс + динамический массив, конструктор копирования |
| 05 | [`archive/05-operator-overloading`](../archive/05-operator-overloading) | Перегрузка операторов |
| 06 | [`archive/06-summary-and-search`](../archive/06-summary-and-search) | Несколько классов: перечень и поиск |
| 07 | [`archive/07-multifile`](../archive/07-multifile) | Многофайловый проект |
| 08 | [`archive/08-aggregation`](../archive/08-aggregation) | Агрегация (композиция) |
| финал | [`src/`](../src) | Наследование |

## Что добавлялось на каждом шаге

1. **Массивы** — база: массив записей фиксированного размера `info X[100]` и набор
   свободных функций (добавить, вывести, удалить, редактировать, сортировать, файлы).
2. **Динамические массивы** — массив переехал в динамическую память (`new`/`delete`),
   размер растёт по мере добавления записей.
3. **Классы** — та же логика, но собранная в класс `mas` (инкапсуляция данных и методов).
4. **Класс + динамический массив** — класс `mas` хранит `info* px`; появляются
   конструктор копирования и деструктор (правило трёх).
5. **Перегрузка операторов** — `operator>>`, `operator<<`, `operator>` упрощают
   ввод/вывод и сравнение записей.
6. **Перечень и поиск** — добавлены классы `masB` (группировка по товариществам) и
   `masC` (поиск участков дороже заданной цены).
7. **Многофайловый проект** — код разнесён по заголовкам и файлам реализации.
8. **Агрегация** — класс `agregate` владеет объектами `mas`/`masB`/`masC`.
9. **Наследование (финал)** — вместо владения используется иерархия
   `mas → masB → masC`.

## Два дизайна одной задачи

Этапы 08 (агрегация) и финал (наследование) решают одну задачу двумя способами:

- **Агрегация** — «объект-владелец» содержит подсистемы (отношение *has-a*).
- **Наследование** — один класс расширяет другой (отношение *is-a*).
